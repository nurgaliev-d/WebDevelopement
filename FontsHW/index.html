Подключение шрифтов в HTML

Это пример страницы, где используются шрифты из разных источников: Google Fonts для заголовков и локальный шрифт для основного текста.

Google Fonts для заголовков

Заголовки используют внешний шрифт Playfair Display, который загружается через тег link из Google Fonts.

Локальный шрифт для текста

Основной текст использует локальный шрифт через правило @font-face. Это позволяет подключать собственные файлы шрифтов.

В CSS указаны альтернативные шрифты через запятую. Если основной шрифт недоступен, браузер автоматически выберет следующий.
